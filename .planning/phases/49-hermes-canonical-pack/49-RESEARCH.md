**What:** Use `index.md`, `source.md`, `style-dna.md`, `<route>-ip.md`, `composition-patterns.md`, `prompt-template.md`, and `qa-checklist.md` under one route directory. [VERIFIED: skills/visual-ip-illustrations/references/ips/gopher/index.md]

**When to use:** Use this for selectable IP routes with independent identity, source, output, prompt, edit, and QA behavior. [VERIFIED: .planning/codebase/ARCHITECTURE.md]

### Pattern 2: Repeated Operational Contract

**What:** Repeat route id, display name, route status, output path, source authority, visual authority, sample boundary, route block, and delivery path in every operational file. [VERIFIED: skills/visual-ip-illustrations/references/ips/caixukun/index.md]

**Why:** Progressive loading means an agent may read only the route-specific files needed for a task, so every file needs enough context to prevent drift. [VERIFIED: skills/visual-ip-illustrations/SKILL.md]

### Pattern 3: Action-Subject Rule

**What:** Hermes Agent performs the central cognitive article action, and the metaphor loses meaning when Hermes is removed. [VERIFIED: .planning/phases/49-hermes-canonical-pack/49-CONTEXT.md]

**Why:** Existing packs reject passive placement because route characters must carry the concept, not decorate it. [VERIFIED: skills/visual-ip-illustrations/references/ips/openclaw/qa-checklist.md]

**What goes wrong:** Pack files restate Hermes without official source, MIT license context, or uploaded conversation attachment authority. [VERIFIED: skills/visual-ip-illustrations/references/ips/hermes/source.md]

### Pitfall 3: Mythology Drift

**What goes wrong:** Hermes route output becomes a Greek messenger or deity scene. [VERIFIED: .planning/phases/49-hermes-canonical-pack/49-CONTEXT.md]

**How to avoid:** Include mythological failure terms in style vetoes, prompt constraints, edit repair, QA checks, and delivery judgment. [VERIFIED: .planning/phases/49-hermes-canonical-pack/49-CONTEXT.md]

### Pitfall 4: Generic Anime Assistant Drift

**What goes wrong:** The character becomes a generic anime assistant, monochrome girl, or fashion mascot without Hermes uploaded-image markers. [VERIFIED: skills/visual-ip-illustrations/references/ips/hermes/source.md]

**How to avoid:** Keep the full marker list together in every file and add uploaded-image identity repair. [VERIFIED: .planning/phases/49-hermes-canonical-pack/49-CONTEXT.md]

### Pitfall 5: Product Poster Drift

**What goes wrong:** The image becomes a product ad, CLI screenshot, web hero, launch poster, logo showcase, or official endorsement-style image. [VERIFIED: skills/visual-ip-illustrations/references/ips/hermes/source.md]
