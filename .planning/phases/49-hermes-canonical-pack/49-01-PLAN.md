# Plan 49-01: Hermes Operational Pack Files

## Goal

Create the six Hermes Agent operational pack files so every file is usable through progressive loading and carries the same route contract, uploaded-image marker set, public sample boundary, shared route block, and output path.

## Inputs

- `.planning/phases/49-hermes-canonical-pack/49-CONTEXT.md`
- `.planning/phases/49-hermes-canonical-pack/49-RESEARCH.md`
- `skills/visual-ip-illustrations/references/ips/hermes/source.md`
- Existing pack precedents under `skills/visual-ip-illustrations/references/ips/caixukun/`, `gopher/`, and `openclaw/`.

## Shared Required Header Contract

Every new Hermes operational file must include these exact concepts in a compact route header:

- Route id: `hermes`.
- Display name: Hermes Agent.
- Route status: `source-reviewed`.
- Output path: `assets/<article-slug>-hermes/`.
- Source authority: `source.md`.
- Uploaded visual authority: conversation attachment `Generated image 1 (16).jpeg`.
- Official source context and MIT license context.
- Public sample review boundary: public generated Hermes samples require release review before appearing in public examples or release surfaces.
- Shared route block: generic anime or assistant drift, mythological Hermes imagery, missing headset, missing bob-hair highlight silhouette, missing black sleeveless dress, missing collar tag, missing stockings or platform heels, product-poster drift, passive placement, route leakage, excessive text, copied composition, official endorsement, affiliation, sponsorship, approval claim, and impersonation all fail the route.
- Save accepted Hermes Agent output under `assets/<article-slug>-hermes/` with an ordered English slug filename such as `01-topic-name.png`.

Every new Hermes operational file must include the full uploaded marker set:

- monochrome full-body logo-style character
- black bob haircut with bright highlights
- headset or earpiece
- black sleeveless dress
- white collar tag with an `A`-like mark
- black thigh-high stockings
- platform heels
- slender fashion-figure posture
